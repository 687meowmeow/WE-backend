This has been tried before, but unfortunately the direct connection won't work because Wine/Proton is missing an API in the Windows bcrypt library that we are using.

You can still try exporting a project and then sending it to the phone directly. We haven't heard back yet from anyone if this worked out or not: https://help.wallpaperengine.io/en/mobile/pairing-fixes.html#backup-solution-manually-importing-a-wallpaper-file-mpkg

Exporting a video wallpaper is really simple and I would be surprised if that won't work, but you could even just transfer the video files directly and skip the project files anyway.

Exporting a scene requires texture conversions and in high-performance mode even video recording through Media Foundation. The former might work but the latter requires a bunch of infrequently used APIs that might not all be available.

**How pairing works, from the binary's strings and imports**

1. **Discovery.** The UI calls `discoverMobileDevices`. It enumerates every network adapter with `GetAdaptersAddresses` and logs "Starting mobile discovery on … for %i adapters".
2. **Broadcast.** On each adapter it opens a UDP broadcast socket and sends discovery packets four ways: loopback, remote, wide (`255.255.255.255`), and directed (the adapter's own broadcast address). The log strings for failures such as "Failed broadcasting wide packet" confirm this.
3. **Listener.** The same code calls `bind` and `listen` and accepts the phone's connection with `AcceptEx`.
4. **Pairing identity.** Pairing is keyed on a `pairingguid` and saved as `paireddevices`.
5. **Events and version check.** After the phone connects, the code raises `onMobileDeviceConnected`, `onMobileDeviceDisconnected` and `onMobileDeviceUploadProgress` events to the JS. It rejects incompatible phones with "Mobile version mismatch, connection rejected."

converted from Wallpaper Engine's desktop format into a separate mobile package format, `.mpkg`. This comes from the strings in `wallpaperui.exe` plus the code that launches the converter, so the stages are solid, but I haven't parsed an actual `.mpkg` yet.

**Two formats**

| | Desktop | Mobile |
|---|---|---|
| Extension | `.pkg` (e.g. `scene.pkg`) | `.mpkg` |
| Magic | `PKGV0024` | `PKGM0020` |
| Created by | the normal wallpaper build | `convertProjectToMobile` / `exportMobilePkg` |

`mpkgVersion` and `mpkgsupport` are the version values the app compares against what the phone reports, which is how the "Mobile version mismatch, connection rejected" check works. There is also an `mpkgversionoverride` setting. Internally, the packer uses a virtual path prefix, `MPKG_VFS://`.

**The conversion pipeline**

The transcoder's error strings give the stages in order:

1. Reset the `transcode` working folder and output file, then create the output directory.
2. Copy the wallpaper's files.
3. Create a thumbnail (`preview.jpg` or `preview.gif`, falling back to `nopreview.jpg`).
4. Open the original `scene.pkg` and unpack its files.
5. Copy `project.json`.
6. Convert video and textures (details below).
7. Pack everything into the `.mpkg`.

`prepareSharedMobileAssets` runs separately. It prepares assets shared by all mobile wallpapers, and a compatibility shader set under `assets/zcompat/scene/shaders`.
